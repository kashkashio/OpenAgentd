# OpenAgentd Brand Assets

App-imported brand assets used by React components.

## Files

- `openagentd-app-icon.png` - transparent mascot icon for app chrome / avatar tile
- `octobot-agentd-source.png` - mascot source used for empty states and illustrations

Marketing and documentation exports live in `documents/assets/brand/`. The browser-public copy in `web/public/brand-assets/` is only for direct URL needs such as the favicon and the boot loader. It is a 256 px, 256-colour export of the icon here (about 13 kB, not 288 kB), because it never shows above 88 px; regenerate it from this file instead of copying this file over it.
